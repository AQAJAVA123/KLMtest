# KLM Automated UI Testing Project

## Описание

Этот проект содержит автоматизированные UI-тесты для сайта [klm.ie](https://www.klm.ie), написанные на Java с использованием **Selenium WebDriver**, **TestNG**, и **Page Object Model**.  
Тесты покрывают основные сценарии поиска авиабилетов, проверку состояния кнопки, поведения форм и валидацию пользовательского ввода.

Ссылка на Excel-файл с 10-ю тестами:

## Автоматизированные тесты

### Реализованные тест-кейсы:
| ID      | Название                                  | Техника тест-дизайна   |
| ------- | ----------------------------------------- | ---------------------- |
| TC-001  | Успешный поиск авиабилета                 | Классы эквивалентности |
| TC-002  | Пустое поле "Откуда"                      | Классы эквивалентности |
| TC-004  | Поиск в одну сторону (One-way)            | Классы эквивалентности |
| TC-005  | Активность кнопки "Search" при вводе      | Диаграмма состояний    |
| TC-008  | Пассажиры и класс (комбинации)            | Попарное тестирование  |


## Как запустить тесты

1. Клонируйте проект:
```bash
git clone https://github.com/your-username/klm-test.git
cd klm-test
```

3. Запуск всех тестов:
```bash
mvn clean test
```

## Используемые техники тест-дизайна

| Техника               | Применение                                                  |
|----------------------|-------------------------------------------------------------|
| **Классы эквивалентности** | Ввод валидных и невалидных значений в форму               |
| **Диаграмма состояний**   | Проверка поведения кнопки “Search” при разных состояниях формы |
| **Попарное тестирование** | Минимальное покрытие всех пар значений: пассажиры × класс |
